# LiveTalk release page

Vite + React + Tailwind landing page for Chobits-Chii-LiveTalk. It reads the latest GitHub Release from `Anime2Real/Chobits-Chii-LiveTalk-Release` and lists platform installers.

```bash
npm install
npm run dev
npm run build
```

Deployed to GitHub Pages by `.github/workflows/deploy.yml`.
